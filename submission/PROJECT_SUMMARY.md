MARSCOPE is an interactive web application for Mars surface exploration and mission planning, built for the NASA Space Apps Challenge 2026. It integrates real NASA and USGS data—including the MGS MOLA global DEM (463 m/pixel, CC0) and the IAU Gazetteer of Planetary Nomenclature—into a dark-themed, map-first interface designed for accessibility and scientific accuracy.

Core functionality includes: an interactive Mars map with MOLA hillshade, colorized elevation, and derived slope layers; click-to-inspect elevation sampling from the actual MOLA DEM with source attribution and uncertainty labels; great-circle distance measurement using the correct Mars radius (3,396.19 km); elevation profiles along user-drawn lines; slope visualization derived via Horn's method; searchable named features from the IAU Gazetteer (40+ pre-loaded Mars features with coordinates and metadata); and a candidate route planner that computes total distance, cumulative ascent/descent, and maximum slope—all explicitly labeled as derived measurements with stated resolution limits and caveats.

The application uses a minimal, permissively-licensed stack: Leaflet + Proj4Leaflet for a custom Mars coordinate reference system (planetocentric, east-positive longitude, 3,396.19 km sphere), optional FastAPI/rio-tiler backend for on-demand MOLA COG tile serving, and lazy-loaded CesiumJS for optional 3D view. All code is MIT-licensed; all data sources are public domain or CC0 with in-app attribution.
